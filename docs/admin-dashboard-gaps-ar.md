# النواقص والتحسينات المتبقية — لوحة الإدارة

## الحالة الحالية

تم ربط وحدات لوحة الإدارة الأساسية مع Laravel API، بما يشمل المنتجات، الطلبات، العملاء، المخزون، المدفوعات، التسويات، المراقبة، التجارة الاجتماعية، وقواعد الصلاحيات. كما تمت إضافة عدادات حقيقية للطلبات والرسائل والتعليقات والمحادثات.

## أولويات التحسين المتبقية

### أولوية عالية

- **اختبارات تكامل آلية:** إضافة smoke tests لمسار تسجيل الدخول، قراءة قائمة الطلبات، تعديل منتج، إنشاء شحنة، وتأكيد الدفع.
- **اختبارات RBAC:** التحقق آليًا من أن كل دور يرى ويعدل الوحدات المسموح بها فقط، مع اختبار منع الوصول من الـAPI وليس الواجهة فقط.
- **معالجة الجلسة الموحدة:** عرض رسالة انتهاء الجلسة وإعادة التوجيه لتسجيل الدخول في كل طلب API يعيد 401، مع منع تكرار رسائل الخطأ.
- **تفعيل queue worker في بيئة التشغيل:** تشغيل معالجة outbox والرسائل الاجتماعية والمهام المؤجلة، مع مراقبة فشل الوظائف وإعادة المحاولة.
- **إكمال إعداد مزودي الذكاء الاصطناعي والتجارة الاجتماعية:** حفظ مفاتيح المزودين وروابط Webhook في بيئة سرية، ثم اختبار الإرسال الفعلي لكل قناة.

### أولوية متوسطة

- **Pagination موحد:** استخدام `meta.total` في جميع الجداول بدل تحميل عدد كبير من الصفوف محليًا، خصوصًا الطلبات والتفاعلات الاجتماعية.
- **تحديث مباشر للمحادثات:** إضافة polling أو WebSocket للمحادثات والرسائل الجديدة بدل التحديث اليدوي.
- **تحديث عدادات لوحة التحكم:** إضافة فترة زمنية قابلة للاختيار (اليوم، الأسبوع، الشهر) ومقارنة حقيقية بالفترة السابقة.
- **تحسين تقارير التسويات:** عرض الفروقات حسب نوعها (تحصيل، شحن، مرتجع، استرداد) مع تمييز السجلات غير المتطابقة.
- **تصدير موحد:** إضافة CSV/Excel للتقارير، العملاء، المنتجات، الحركات، والتفاعلات الاجتماعية مع احترام الصلاحيات.
- **ترجمة رسائل التحقق:** توحيد رسائل أخطاء Laravel بالعربية وربطها برسائل مفهومة في الواجهة.

### أولوية منخفضة

- تقسيم `App.tsx` و`api.ts` إلى وحدات أصغر حسب المجال.
- إضافة سجل تدقيق قابل للبحث والتصفية للمستخدمين الإداريين.
- إضافة مراقبة أداء وصحة API مع تنبيهات عند ارتفاع الأخطاء أو بطء الاستجابة.
- تحسين الوصولية: التنقل بلوحة المفاتيح، focus states، وتسميات ARIA للنوافذ والجداول.
- إضافة اختبارات responsive فعلية على أحجام الهاتف واللوحي.
